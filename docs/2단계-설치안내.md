# 2단계 설치 안내 — Supabase 연결

대표님이 하실 일은 **딱 3개**입니다. 15분이면 끝납니다.
코드 수정은 없습니다. 계정 만들고 값 복사해서 붙여넣는 게 전부입니다.

---

## 왜 이걸 하나요?

지금은 스레드 토큰이 **브라우저 쿠키**에 있습니다. 그래서 두 가지가 안 됩니다.

1. **계정을 여러 개 못 담습니다** — 쿠키 한 칸에 계정 하나
2. **예약 발행이 안 됩니다** — 쿠키는 브라우저에 있어서, 대표님이 컴퓨터를 끄면 서버가 토큰을 읽을 방법이 없습니다

Supabase는 무료 데이터베이스입니다. 토큰을 여기로 옮기면 서버가 혼자 돌 수 있게 됩니다.

> 💡 **60일 시한폭탄**
> 스레드 장기 토큰은 60일짜리이고, **만료되면 되살릴 수 없습니다** (7계정 전부 재인증).
> DB로 옮겨야 자동 갱신 장치를 붙일 수 있습니다. 이게 2단계를 먼저 하는 진짜 이유입니다.

---

## 1단계 · Supabase 프로젝트 만들기

1. https://supabase.com 접속 → **Start your project** → GitHub 계정으로 로그인
2. **New project** 클릭
3. 입력값:
   - **Name**: `dbtwo-threads` (아무거나 괜찮습니다)
   - **Database Password**: 자동 생성 버튼을 누르고 **어딘가에 저장**해두세요
     (이 비밀번호는 우리 코드에서 안 씁니다. 나중에 DB를 직접 열어볼 때만 필요합니다)
   - **Region**: **Northeast Asia (Seoul)** ← 한국 서버가 가장 빠릅니다
   - **Plan**: Free
4. **Create new project** → 준비되는 데 1~2분 걸립니다

---

## 2단계 · 표(테이블) 만들기

1. 왼쪽 메뉴에서 **SQL Editor** 클릭
2. **New query** 클릭
3. 이 저장소의 **`supabase/schema.sql` 파일 전체**를 복사해서 붙여넣기
4. 오른쪽 아래 **Run** 클릭 (또는 Ctrl+Enter)
5. **`Success. No rows returned`** 이 나오면 성공입니다

> 표가 잘 만들어졌는지 확인하려면 왼쪽 메뉴 **Table Editor** 에서
> `threads_accounts`, `scheduled_posts`, `post_metrics`, `account_metrics`
> 4개가 보이면 됩니다.

---

## 3단계 · 열쇠 2개 복사하기

1. 왼쪽 메뉴 맨 아래 **Project Settings**(톱니바퀴) → **API**
2. 여기서 **2개**를 복사합니다:

| 화면에 적힌 이름 | 생김새 | 붙여넣을 곳 |
|---|---|---|
| **Project URL** | `https://abcdefgh.supabase.co` | `SUPABASE_URL` |
| **service_role** (secret) | `eyJ...` 로 시작하는 아주 긴 문자열 | `SUPABASE_SERVICE_ROLE_KEY` |

3. 프로젝트 폴더의 `.env.local` 파일을 열어서 맨 아래에 추가:

```
SUPABASE_URL=여기에_Project_URL
SUPABASE_SERVICE_ROLE_KEY=여기에_service_role_키
CRON_SECRET=아무거나_긴_무작위_문자열
```

`CRON_SECRET`은 대표님이 직접 아무렇게나 지으시면 됩니다.
(예약 발행을 실행하는 주소를 아무나 호출하지 못하게 막는 자물쇠입니다.
`3jf9Kd82mQpZx7Lw0aBvNc4` 같은 20자 이상 아무 문자열이면 됩니다)

4. **Vercel에도 똑같이 넣어주세요**
   vercel.com → 프로젝트 → **Settings** → **Environment Variables** → 위 3개 추가
   → 그 다음 **Deployments** 탭에서 맨 위 배포의 **⋯ → Redeploy**

## ⚠️ 보안 주의 — 딱 두 가지만

1. **`service_role` 키는 마스터 키입니다.** 이걸 가진 사람은 DB의 모든 것(= 스레드 토큰 전부)을 볼 수 있습니다.
   - 채팅창·카톡·이메일에 붙여넣지 마세요
   - `.env.local` 파일에만 넣으세요 (이 파일은 `.gitignore`에 등록돼 있어 GitHub에 안 올라갑니다)
   - 옆에 있는 **anon** 키와 헷갈리지 마세요. `anon`은 공개용이라 우리 코드에선 안 씁니다.
2. **`NEXT_PUBLIC_` 접두사를 붙이지 마세요.** 붙이면 브라우저에 그대로 노출됩니다.

혹시 실수로 어딘가에 노출했다면, Supabase의 같은 화면에서 키를 **재발급(Reset)** 하면 됩니다. 되돌릴 수 있으니 당황하지 마세요.
